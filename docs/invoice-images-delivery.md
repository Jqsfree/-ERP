# 开单图片版交付记录（2026-11-08）

版本0.1.3+4；数据库仍为v9，无新增业务迁移。范围为新单自动存相册、历史/改单手动存图、保留分享、清理软件内置测试字样。完整ERP退款等范围仍按原验收报告推进，不能据此宣布全ERP发布通过。

## 实现

- 新单提交成功后进入详情，自动保存一次。改单和补收款不触发自动保存，历史详情提供“保存图片”。失败不重新开单、不撤销已提交订单。
- 复用横版2160×1520 PNG，每9行一页。文件名含单号/版本、导出时间、随机分组及页码，目录为Pictures/凯堡软装；不会覆盖旧图。
- Flutter通过image_album通道调用原生Android。Android10及以上使用MediaStore/IS_PENDING，完成写入及发布后才计成功；Android7–9按需申请WRITE_EXTERNAL_STORAGE（maxSdkVersion28），写完后等待相册索引。
- 多页失败返回已保存页索引，当前详情页重试只发送剩余页；未完成文件尽力清理，不把部分成功报为全部成功。关闭进程后没有持久导出任务，重新打开可手动另存整套；业务记录不受影响。
- 首页、备份说明已清理测试/开发版字样；未开放功能继续如实注明。用户数据、源码测试及验收文档不按关键词删除。
