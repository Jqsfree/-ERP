# PRD：凯堡软装 ERP 开单系统

## 一句话目标

让软装商户在 Android 手机上无网络也能正确开出销售出货单、记录收款、打印分享，并逐步形成有凭证的进销存账务闭环。

## 用户与场景

- 柜台开单员：手机上搜索产品，录入米数与门幅，生成出货单并发送/打印。
- 店主：查看客户欠款、销售单、付款、出入库和费用。
- 仓管：根据出库单实际发货并确认库存流水（第二阶段）。

## 原图对齐

示例 2026-11-05 的凯堡软装销售出库单：

- 单号格式 `XS202611050001`
- 客户：示例客户，销售日期：2026-11-05
- 明细：产品 `KB56-34`，数量 `37`，下单门幅 `2.8`，总数量 `103.6`，单价 `13.99`，金额 `1449.36`
- 优惠 `0.36`，合同金额 `1449.00`，已收 `0.00`，未收 `1449.00`
- 票据须包含订货信息、制单人、收货人签名、售后说明等可定制内容（后续）。

## 功能优先级

### P0：可用销售单闭环

- 客户/产品资料添加、查询和选择。
- 多行产品、型号/规格、米数、门幅、面积、单价、金额、单级优惠、首收款。
- 唯一单号、历史查询、后续收款、客户欠款。
- 单据 PDF 生成、系统打印/分享，CSV 交付。
- 离线数据持久化；基础单元测试。
- 交付条件：源代码 + Android 可安装测试 APK + QA 报告。

### P1：真正的进销存闭环

- 供应商、采购入库、商品库存流水（按批次/仓库/单位）。
- 销售单确认与发货分开；出库仅按实际发货执行一次。
- 退货引用原销售明细，库存反向入库与退款/冲应收分开。
- 单据取消/修订采用更正单而非静默覆盖历史。
- 银行/微信/支付宝收款台账；日结、对账、账龄报表。
- 单据导入导出 XLSX、加密备份与恢复；无网络可全部操作。

### P2：多设备与管理

- 角色权限、员工操作日志、配置化打印版式。
- 可选服务端同步与冲突解决、多个店铺/仓库。
- 扫码、蓝牙小票机、照片、报价单与销售统计。

## 约束

- 不采集与业务无关的隐私，不依赖账号/第三方云才能开单。
- 所有金额按整型分表示；长度/门幅按千分之一米表示；严禁浮点累计。
- 不允许仅因 UI 按钮点击就改库存和收款流水，业务动作须以事务完成。
- 不把业务单据的打印显示整数误认为账务金额可随意四舍五入到元。
- 不在未建立正确库存计量单位前自动扣减库存。
