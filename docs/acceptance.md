## 本地验证记录（2026-11-06）

- `flutter test`：7 项测试全部通过，包括金额计算、首页入口和新增客户表单输入。
- `flutter analyze`：没有错误；有 3 条 `curly_braces_in_flow_control_structures` 信息提示，建议给 `for` 循环语句加花括号。
- Android 15 模拟器：Debug APK 构建、安装和启动成功。首次启动时 Flutter 工具丢失了 VM service/DevFS 连接；再次启动成功。之后读取到的 Dart 运行时错误为零。
- 输入问题：用户报告新增客户时无法输入。Widget 单测能通过 `enterText` 把姓名和电话写入表单控制器，但这不验证模拟器的软键盘/硬件键盘输入链路；模拟器上的实际键盘问题尚未复现或定位，不能据此认定已解决。
- 构建警告：`share_plus` 使用 Kotlin Gradle Plugin，Flutter 提示未来版本可能需要插件迁移；当前不影响 Debug 构建。

说明：Widget 单测和模拟器启动成功不等于真实 Android 手机验收通过。持久化恢复、真实键盘输入、收款、导出、打印和设备兼容性仍需按上表测试。CI 配置在 GitHub 仓库 push 后运行。
