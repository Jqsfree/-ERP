## 已实现

- 页面清单、统一标准、业务缺口及门禁：[验收标准](../UI_ACCEPTANCE_STANDARD.md)。
- 部分转余额：同一事务重新查询来源、归属段、修订号和剩余金额，防止并发超额。
  同键同内容返回原结果，同键不同内容拒绝；不产生现金事件。
- 备份按每笔事件验证金额不超过当时可处理金额，兼容既有整笔转入。
- 金额弹窗验证必填、精度、正数和上限；提交禁重复；不确认结果时保留金额与原请求重试。
- 销售详情隐藏物理打印入口，保留PDF分享、图片保存/分享及既有CSV输出。
- 备份页面可选择真实.kberp文件做隔离恢复验证：有界读取、解密、校验、恢复独立临时数据库、
  关闭重开、逐表值比较及完整性检查；结束后清理自己的临时库。当前业务库不参与写入。
- 备份文件选择与密码期间锁定操作；恢复确认长内容可滚动。
